## Module Summary

### Part 1 – Variables & Data Types
- Variable declaration and initialization
- Primitive and reference types
- Boolean logic and type conversion
- Scope management and variable handling

### Part 2 – Loops & Functions
- `for`, `while`, and `do...while` loops
- Function declarations and reusable functions
- Parameter handling and callback examples
- Practical looping and function patterns

### Part 3 – Objects
- Object creation and property access
- Object methods and nested structures
- JSON serialization and parsing
- Data modeling with objects

### Part 4 – Arrays
- Array creation and manipulation
- `map()`, `filter()`, `reduce()` examples
- Sorting and searching arrays
- Working with nested arrays

### Part 5 – Asynchronous JavaScript
- Callback patterns and error handling
- Promises and chaining
- `async` / `await` usage
- `Promise.all()` examples

  - Pulsing due-date alerts

  - Time-until-due calculations
