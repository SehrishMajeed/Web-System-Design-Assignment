# JavaScript Fundamentals Showcase

A comprehensive guide and interactive demonstration of core JavaScript concepts, featuring a practical **Interactive Task Manager** built with vanilla JavaScript, HTML, and CSS.

---

## 📖 Project Overview

This repository serves as a modular guide to modern JavaScript programming. It is structured into clear, topic-focused modules that cover essential programming concepts. The main interface is available in `index.html`, providing an interactive dashboard to explore each topic and its corresponding source code.

The project demonstrates:
- JavaScript fundamentals through practical, tested examples
- Modular code organization and best practices
- Clean, responsive UI presentation
- Interactive module selection
- A fully functional applied project (Interactive Task Manager) for real-world practice

---

## 🗂️ Project Structure

- `index.html` — The main dashboard interface
- `style.css` — Global styling and modern UI effects
- `Dashboard.js` — Logic for the interactive dashboard
- `variables.js` — Examples of Variable declaration, scope, and types
- `loops.js` — Iteration patterns (`for`, `while`, `do...while`)
- `functions.js` — Function declarations, expressions, and callbacks
- `objects.js` — Object creation, methods, and nested structures
- `arrays.js` — Array manipulation (`map`, `filter`, `reduce`)
- `async.js` — Asynchronous JS (Promises, `async`/`await`)
- `bonus.js` — Logic for the Interactive Task Manager
- `*.pdf` — Detailed conceptual notes corresponding to each module

## 🛠️ Module Breakdown

### Part 1 – Variables & Data Types
- Variable declaration and initialization (`var`, `let`, `const`)
- Primitive and reference types
- Boolean logic and type conversion
- Scope management and variable handling

### Part 2 – Loops & Functions
- Iteration logic with `for`, `while`, and `do...while` loops
- Reusable function patterns
- Parameter handling and callback examples

### Part 3 – Objects
- Object creation and property access
- Object methods and nested structures
- JSON serialization and parsing
- Data modeling with objects

### Part 4 – Arrays
- Array creation and basic manipulation
- Higher-order functions: `map()`, `filter()`, `reduce()`
- Sorting, searching, and working with nested arrays

### Part 5 – Asynchronous JavaScript
- Callback patterns and basic error handling
- Promises and chaining
- Modern `async` / `await` syntax and `Promise.all()`

## 🚀 Featured Project: Interactive Task Manager

Included is a fully functional web application demonstrating DOM manipulation, event handling, and data persistence:

- **Smart Task Management:** Create, delete, and edit tasks.
- **Organization:** Priority and category classification.
- **Deadline Tracking:** Due-date tracking with smart notifications.
- **Real-time Metrics:** Progress bars and live task counts.
- **Filtering & Sorting:** Advanced sorting by priority or date, and search integration.
- **Local Persistence:** Uses LocalStorage to save tasks across browser sessions.
- **Modern UI:** Smooth animations, glassmorphism design, and responsive layouts.

## 💻 How to Run Locally

This project requires **no build tools or external dependencies**.

1. Clone the repository:
   ```bash
   git clone https://github.com/yourusername/javascript-fundamentals.git
   ```
2. Navigate to the project folder.
3. Open `index.html` in your modern web browser (Chrome, Firefox, Edge).
4. Use the dashboard to browse through topics, read the code examples, and interact with the Task Manager.

This repository was originally developed as a comprehensive semester project for a university course in **Web Systems and Technology**. The primary objective was to demonstrate a deep, practical understanding of JavaScript fundamentals, modular code design, and modern web development practices without relying on external libraries or frameworks. 

While it originated as an academic assignment, it has been structured and refined to serve as a professional portfolio piece and a valuable learning resource for others exploring vanilla JavaScript.
